Ficha Técnica del Prototipo (Fase 1.4)

Alineación con Matriz de Riesgos (Diapositiva 16):

En previsión del riesgo institucional (tiempo de aprobación y configuración de credenciales OAuth2 por el departamento de TI), este avance opera sobre un entorno Sandbox (Mock Fiel) que implementa exactamente el esquema JSON de la API REST oficial de KOHA (/api/v1/biblios).

Tecnología Backend: ASP.NET Core (.NET 10)
Catálogo Destino: Biblioteca Central Mexicali
Flujo de Autenticación: OAuth 2.0 (Client Credentials)
Motor de Lenguaje (SLM): Qwen 2.5 (0.5B) Fine-Tuned LoRA SFT • GGUF Q4_K_M en CPU (LLamaSharp)

Endpoints de Integración Implementados:

  • • POST /api/chat → Orquestador conversacional
  • • POST /api/catalog/search → Consulta directa catálogo Koha
  • • GET /api/status → Monitoreo de modo y registros indexados
  • • POST /api/v1/oauth/token → Soporte Client Credentials
